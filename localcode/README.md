# localcode

使用本地 Ollama 模型 (qwen3b-vl:4b) 进行编程辅助的项目。

## 背景

- 本地模型是小型模型 (3B parameters)
- 智力与上下文长度有限
- 目标：通过任务拆分策略，让小模型也能完成较复杂的编程任务

## 核心策略

1. **任务拆分** - 将大任务拆分为可独立完成的小任务
2. **文档驱动** - 用外部文档承载上下文，不依赖模型内存
3. **渐进实现** - 逐步完成子任务，每步可验证
4. **自适应** - 结果不达预期时继续拆分

## 功能规划

- [x] 连接 Ollama API (qwen3b-vl:4b)
- [ ] 任务拆分框架
